# 用户可见输出模板

默认用中文输出。不要把网站收益宣传当成事实。

## 1. 今日结论（先说）

用 2-4 行说明：

- 检测时间
- 新增多少条
- 有没有真正可验证的项目
- 今天最推荐的 1 个方向

## 2. 推荐项目（按优先级）

对每个推荐项目写：

### 项目名
- 原文链接
- 为什么值得做（转成服务/产品，不是跟做课程）
- 目标客户
- 可卖什么 / 怎么报价
- 7 天验证动作
- 风险与边界
- 推荐指数

## 3. 可观察但暂不主攻

列出次优项目，并说明为什么只观察。

## 4. 明确不建议

表格列出：项目、原因。

## 5. 最终建议

给出一条主线：

> 今天优先验证：XXX

并给出下一步可执行动作（报价单 / 话术 / 样品 / 获客清单）。

- 历史报告：`E:\machengji\maomp-monitor\reports\`
- 状态文件：`E:\machengji\maomp-monitor\state.json`
