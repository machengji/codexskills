# 评分与筛选规则

## 输入源

- 默认 RSS：`https://www.maomp.vip/feed/`
- 正文优先抓取 `<article>`，失败再退回整页文本
- 标题收益数字不作为事实

## 分数模型（0-100）

基础分：45

### 加分

- 业务方向词（AI/Codex/自动化/软件/获客/企业服务/GEO/外贸/标书等）：每项 +4，最多 +20
- 落地线索词（流程/SOP/案例/客户/交付/报价/售后等）：每项 +3，最多 +15
- 出现“真实客户/企业客户/本地商家/服务商/收费/报价/交付”：+10
- 出现“低成本/无需囤货/开源/免费工具”：+5

### 扣分

- 夸大收益词（日入/月入/躺赚/保底/零成本/不封号等）：每项 -5，最多 -25
- 风险词（挂机/挂G/外挂/破解/搬运/刷量/男粉/跳人脸/防风/报白等）：每项 -9，最多 -45
- 会员/课程/教程/付费文章包装：-8

## 级别

| 级别 | 条件 |
|---|---|
| 可优先验证 | score >= 65，且风险词 < 2 |
| 可小成本验证 | 45 <= score < 65 |
| 谨慎观察 | 35 <= score < 45 |
| 不建议 | score < 35，或风险词 >= 2 |

## 人工二次判断（必须）

脚本只做初筛。对“可优先验证 / 可小成本验证”项目，还要判断：

1. 是否能找到真实付费客户
2. 是否有最小可交付样品
3. 7 天内能否小额验证
4. 是否依赖买课/买软件/投广告
5. 是否存在封号、侵权、资金、灰产风险

## 推荐转化原则

优先把线索转成服务/产品，而不是“跟做副业”：

- AI 课程 → AI 自动化交付服务
- GEO 课程 → 企业 AI 搜索获客服务
- 标书课程 → 企业方案提效服务
- 电商课程 → 商家代运营/素材/系统服务
- 工具分享 → 工具 + 安装配置/培训服务

## 明确不推荐

- 挂机、挂G、外挂、破解
- 搬运、刷量、刷单、规避风控
- 男粉写真、色情擦边
- “日入/躺赚/保底/当天变现”作为唯一证据
- 未验证前先付会员费或买高价课

## 会员内容加分

- 抓到会员下载链接：+4
- 看到课程目录/大纲：+3
- 仍被会员门控挡住：-6
