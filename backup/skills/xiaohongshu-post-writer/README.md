# Xiaohongshu Post Writer Skill

一个通用、可切换人设的小红书图文笔记写作 Skill。它可以根据主题、素材、照片和账号人设生成或改写标题、正文、封面文字、话题标签与图片排序建议，并在交付前检查平台合规与“AI 味”。

## 什么时候触发

当用户提出以下需求时使用：

- 写小红书文案、笔记、标题、封面文字或话题标签
- 根据照片配文案、安排图片顺序
- 按指定账号人设改写，或让同一套流程适配不同人设
- 去除模板感、广告腔或明显的 AI 生成痕迹
- 检查夸大宣传、隐私、引流、互动诱导、AI 内容标识等风险
- 优化浏览、收藏、评论或搜索承接，但不承诺流量结果

## 输入

最小输入只需要一个主题。效果更好的输入通常包括：

- 主题与发布目的
- 必须包含的事实、经历、数据或产品信息
- 照片及每张照片的背景
- 账号人设、口吻、禁用表达
- 期望篇幅、受众与转化目标

人设不是写死在 Skill 里的。使用 `assets/persona-profile-template.md` 建立账号档案后，同一套工作流可以服务不同创作者。

## 输出

默认先给可直接编辑的成稿，再按需要补充：

- 标题与备选标题
- 正文
- 封面文字
- 话题标签
- 图片顺序和单图职责
- 事实待确认项与合规提醒

## AI 文案与流量

本 Skill 不把“AI 生成”简单等同于“必然限流”，也不声称能绕过 AI 检测。它优先提升内容的真实性、信息密度、图文一致性和人设稳定性，并提示在适用场景下进行 AI 内容标识。平台分发受内容质量、用户反馈、账号状态、搜索相关性和规则变化等多种因素影响，任何文案都不能保证流量。

## 安装

将本仓库目录复制到 Codex skills 目录，或使用支持从 GitHub 仓库安装 Skill 的安装工具：

```text
https://github.com/wenhua6610/xiaohongshu-post-writer
```

主入口是 `SKILL.md`，其余规则、模板和输出结构位于 `references/`、`assets/`、`agents/` 与 `evals/`。

## 使用示例

```text
主题：普通上班族第一次用 AI 整理周报
素材：原来要花 2 小时，现在大约 30 分钟；不要写成效率提升 4 倍
照片：电脑桌面、整理前的笔记、最终周报截图
人设：理性克制的产品经理，少用感叹号，不说“神器”
目标：让读者愿意收藏并照着做
请生成一篇小红书图文笔记，并检查隐私和夸大表达。
```

## 说明

该 Skill 只生成、改写和审核草稿。除非用户另行明确授权，不自动发布内容，也不执行点赞、关注、评论或其他账号互动。
