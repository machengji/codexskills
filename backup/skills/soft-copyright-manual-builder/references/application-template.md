# 申请表信息.txt 模板

```
1.★软件全称：[软件名称]
2.★版本号：V1.0
3.★开发的硬件环境：CPU：[CPU型号]，内存：[内存大小]
4.★运行的硬件环境：CPU：[CPU型号]，内存：[内存大小]，硬盘：[硬盘大小]
5.★开发该软件的操作系统：[操作系统版本]
6.★软件开发环境 / 开发工具：[IDE和工具集]
7.★该软件的运行平台 / 操作系统：[运行平台]
8.★软件运行支撑环境 / 支持软件：[运行时/框架/数据库]
9.★编程语言：[编程语言，不含HTML/CSS/Vue]
10.★源程序量：[14500-18600之间随机数]
11.★开发目的：[50字以内]
12.★面向领域 / 行业：[50字以内]
13.★软件的主要功能：[1000-1300字]
14.★技术特点：[100字以内]
15.★软件的技术特点选项：[从列表选一个]
16.★页数：60页
17.★软件分类：应用软件
```

## 字段规则

- **字段 9 编程语言**：仅写真正的编程语言（Python, Java, TypeScript, Go, C++ 等），不写 HTML/CSS/Vue/React 等
- **字段 10 源程序量**：纯数字，在 14500-18600 之间取随机值
- **字段 11 开发目的**：50字以内，直击痛点，说明解决什么问题
- **字段 13 主要功能**：1000-1300字，详述模块架构、核心逻辑、数据流转
- **字段 14 技术特点**：100字以内，提及算法、架构模式或安全性

## 技术特点选项（15选1）

APP、信息安全软件、游戏软件、大数据软件、教育软件、人工智能软件、金融软件、VR软件、医疗软件、5G软件、地理信息软件、小程序、云计算软件、物联网软件、智慧城市软件

## 格式约束

- 每条记录独占一行，中间无空行
- 字段编号和★符号必须保留
- 顺序不可改变
- 主要功能描述中删除所有换行和空行
- 主要功能和技术特点描述必须在操作手册中有对应体现


## 独创性与反换词要求（强制）

申请表**格式**可参考本模板；**内容**必须按当前软件独立重写，避免版权中心“模板化 / 批量替换关键词”补正。

1. 第11–14项禁止从其他软件申请表复制后只替换软件名、行业词、对象词。
2. 第13项主要功能必须写本软件真实模块、对象、状态流转与结果沉淀，至少能在操作手册中逐项找到对应章节；删掉软件全称后仍应能识别本业务。
3. 第14项技术特点必须对应本项目真实实现，不得写万能“模块化、可视化、高可用”套话充数。
4. 若同级目录存在其他申请表，生成后抽检主要功能连续片段，不得高度同构。
5. 格式门禁（17项、单行、无空行、字数）与独创性门禁同时生效；只满足格式不满足独创性视为不合格。
