# 操作手册截图状态链协议（强制）

> 本协议是合并后技能的核心新增门禁，服务于软著操作手册的截图编排。  
> 目标：让每一张截图都来自真实操作后的**新状态**，相邻截图肉眼可辨、有内容变化或弹框，从而把“同屏近似图 / 换时间 / 换数字 / 轻微滚动 / 短暂 toast”这类模板化观感压到最低。

## 一、状态链定义

每个功能模块的截图必须按真实操作链编排，形成一条**状态链**。状态链的每一环都是一张独立截图，且必须是执行某一步操作之后的可见结果。

**状态链由本项目真实业务流程编译，不套固定链。** 先梳理本案真实操作链（登录→筛选→提交→审核→归档、上传→识别→结果→导出→删除、切换工况→联动→告警→处置 等），再决定截图顺序；禁止把示例链照抄到每个项目。

示例链（仅示意，禁止照抄）：

```text
空白/初始页 → 输入凭据或参数 → 系统评估/计算出结果 → 导出弹窗 → 删除/归档后列表变化
```

其他可接受的状态链示例（同样仅示意）：

```text
列表初始 → 筛选条件 → 结果集变化 → 详情抽屉 → 提交后状态列更新
主工作台 → 切换工况 → 三维/影像/结果区联动 → 告警弹窗 → 处置后告警栈变化
```

## 二、每张截图必须登记

在 `_soft_shots/manifest.json` 或项目验收记录中，为每张拟入手册的截图登记：

| 字段 | 说明 |
|------|------|
| `stepId` | 稳定编号，如 `s03-eval-result` |
| `shotGroup` | 同页/同闭环的一组截图 |
| `action` | 真实操作名，如“输入密码”“点击评估”“点击导出”“删除一行” |
| `beforeState` | 前置状态，如“空白页”“列表含 3 条待评估记录” |
| `afterState` | 后置状态，如“结果区出现 3 项评估结论”“导出弹窗打开”“列表剩 2 条” |
| `visibleChanges` | 至少 2 个肉眼可见的变化区域，如“结果区填充 + 状态列变已评估”“弹窗出现 + 按钮变导出中” |
| `popup` | 是否含弹框/抽屉/详情面板；同组至少 1 张必须含并保持可见 |

## 三、同组截图差异门禁

1. 同一 `shotGroup` 的相邻截图必须来自真实操作，差异必须肉眼可辨。
2. 至少一个步骤打开并保持可见的弹框/抽屉/详情面板，并在其中完成字段变更、筛选、选择或提交；弹框关闭后还要有结果态图。
3. 结果态至少呈现两个业务区域变化（如结果区填充 + 状态列更新 + 按钮态变化）。
4. 只出现时间、数字、光标、轻微滚动或短暂 toast 的截图，删除并重走流程。
5. 禁止用改文件名、换标题、换颜色、换图标冒充状态变化。

## 四、采集规格

- 页面按 **1920 宽度设计**；viewport：`1920×1080`
- `deviceScaleFactor: 1.5`，输出约 `2880×1620`
- 原图宽度不得低于 2880px；100% 检视时中文与控件清晰可读
- 等待字体、数据、弹框、三维/影像联动稳定后再截图；禁止截取加载态、动画态或运动模糊画面
- 文件名语义化，如 `s01-login.jpg`、`s03-eval-result.jpg`、`s04-export-dialog.jpg`、`s05-after-delete.jpg`
- 最终手册 DOCX 单个文件 ≤20MB；超限时压缩内嵌图片（JPEG 质量 ≥80、PNG 转 JPEG、清理未使用媒体），压缩后截图仍须 100% 可读，禁止为压体积牺牲画质

## 五、每张截图配 3–5 行短人话说明（强制）

每张截图在手册正文中配 **3–5 行**简短人话描述，禁止长篇大论、禁止 AI 腔、禁止元叙述。说明固定回答两个问题：

1. **这个页面是执行哪一步操作之后得到的**：写清“操作入口 → 动作 → 页面反馈”。
2. **页面主要元素用途**：写清各区域/按钮/字段是干什么的。

示例（仅示范表达，禁止跨项目整句复用）：

```text
图 3-2 评估结果页
在“评估参数”区输入密码并点击“开始评估”后，结果区出现 3 项结论。
左侧是对象列表，当前选中“1 号测点”；中间结果区显示评估等级与依据；
右侧“处置建议”列出下一步动作。顶部“导出”按钮用于把结果写入报告。
```

- 图注只写业务界面名或状态名，如 `评估结果页`、`导出弹窗-已选 3 条`、`删除后列表-剩 2 条`。
- 正文每图 3–5 行；禁止“整页只有图+图注”，也禁止为凑字数写总结腔。
- 同一完整句子在全手册最多出现 1 次；允许专有名词重复，不允许整段模板句重复。

## 六、验收清单

- [ ] 每个功能模块截图按状态链编排，每张图都是真实操作后的新状态
- [ ] 状态链由本项目真实业务流程编译，未照抄示例链
- [ ] 同组相邻截图差异肉眼可辨，且来自真实业务后果
- [ ] 同组至少 1 张含弹框/抽屉/详情面板并保持可见
- [ ] 结果态至少两个业务区域变化
- [ ] 无时间/数字/光标/轻微滚动/toast 冒充差异
- [ ] 每张截图配 3–5 行短人话说明，回答“哪步操作后得到此页”和“主要元素用途”
- [ ] 图注只写业务界面名或状态名
- [ ] 页面按 1920×1080 设计并铺满全屏（无大面积空白）；截图 1.5x 高清，原图宽度 ≥2880px，100% 可读
- [ ] 截图来自当前项目实际运行，无生图/虚拟图/无关内容
- [ ] 操作手册 DOCX 单个文件 ≤20MB；压缩后截图仍 100% 可读
