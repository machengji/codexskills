# 页面异构、单点纵深与交互密度门禁（硬门禁 + 示例）

> 本文件只保留硬门禁和示例；具体页面组合由本项目业务流决定，禁止照抄示例。

## 硬门禁（强制）

1. **先做 UI 创新指纹、跨项目审计和页面矩阵，再写页面**：登录页、首页和每个业务页都要单独填写矩阵行并通过“名称删除测试、行业替换测试、模板替换测试、标题一致性测试、好看可检测试”。任何页面只靠标题、数字、颜色、图标或网格坐标变化，均判定为模板复用。
2. **编码前先做三案竞争 + frontend-design 精修**：先生成对象/结构、流程/时间、场所/工具三套候选视觉方向，记录评分与淘汰理由；再强制读取并应用 frontend-design，产出色板、字体角色、布局概念、签名元素、动效与反默认审美自检；然后建立系统级 UI 创新指纹。
3. **相邻页面至少改变五项**：主要视觉重心、阅读方向、组件排列、信息层级、图像/画布/三维模型业务角色、工具栏/筛选器/按钮带位置、按钮密铺逻辑、结果/详情/证据/复查面板位置——至少改变其中五项。
4. **页面重复预算**：同一主体骨架最多覆盖两个强相关页面；第三次出现即判定重复。公共壳只允许承载品牌、当前任务和必要全局状态；允许复用原子组件，不允许复用完整页面骨架。
5. **内容、图表与真实网图硬门禁**：每页必须写明名称词根、业务对象、现场判断、页面动作和结果变化；chart 不是必选组件，每个 chart 必须有数据来源、判断结论、联动对象和点击后果；中国境内真实网图案例强制启用（≥6 张本地化，台账含来源/许可/`country: 中国`/省市地点/地点依据/页面与业务角色），外国场景图片必须为 0（用户明确指定除外）。
6. **功能复杂度（工业诊断台级）**：每页 ≥16 有效操作入口、≥5 页面专属动作、≥3 并发工作区（含主解析区 + 对象/工况器 + 规则/结果区）；关键操作有对象/判断/处置语义反馈，不是空“成功”；全站 ≥5 页达到高密度诊断台加强标准。
7. **登录页与标题贴合**：登录页有独立构图，不是通用左右分栏/居中白卡片换肤；首屏可见名称对象或现场工具隐喻；有业务准入语境与业务化失败反馈；软件全称逐字显示，禁止简称/缩写/别称/英文名或英文翻译替代，禁止自行改字、加字、截断。
8. **反复验证记录**：每轮验收必须逐页或抽样至少五页，记录页面职责、布局母版、阅读方向、三维/影像角色、并发工作区、操作入口数、专属操作数、是否触发页面重复预算、组件排列与相邻页差异、真实状态后果与业务语义反馈、结论。

## 直接不通过的情形

- 页面看起来基本一样，或页面缩略拼图中出现三页以上同骨架
- 未完成三案竞争、frontend-design 精修与名称语义映射，或与同级案例十维差异少于七项
- 仍使用无业务理由的固定左栏、顶栏和通用卡片外壳，或全部路由由单一页面生成器和固定面板清单承载
- 操作入口不足 16 个、页面专属操作不足 5 个、并发工作区不足 3 个
- 关键操作无业务语义反馈，或全站达到“高密度诊断台”加强标准的页面少于 5 个
- 模型只换颜色或视角
- 菜单、字段、模型、影像和示例数据与系统名称无关
- chart 没有明确判断用途、数据来源或点击后果
- 中国境内真实网图案例不足门槛、未本地化、无中国地点依据台账，或存在外国场景图片、无关装饰网图/未说明授权图片
- 操作没有真实后果或没有写入留痕
- 违反页面重复预算，或只做了构建检查，没有做逐页面结构检查
