# 操作手册去 AI 味增强规则（软著场景专用）

本文件是 humanizer 系列与 qu-ai-wei 等去 AI 味技能在「软件操作手册」场景下的增强规则。目标文本是软著申报、项目交付用的操作手册（Word/PDF）或项目内 操作手册.md 时，在各自技能通用规则之上追加本规则。

## 一、场景定位

- 手册站位：项目研发组写给现场操作员/复核员的操作说明，不是对话答复、不是产品宣传、不是论文、不是教程。
- 每个关键段落必须能对上真实页面：菜单、按钮、字段、状态、提示语。
- 手册服务于「照着能操作」，不是「读起来有文采」；信息密度优先于修辞。

## 二、手册专用禁用词（正文出现即返工，专有名词引用除外）

| 类型 | 示例（含近义） |
|------|----------------|
| 总结腔 | 综上所述、总而言之、由此可见、整体而言、一言以蔽之 |
| 提醒腔空转 | 值得注意的是、需要注意的是、需要指出的是、不难发现、显而易见 |
| 元叙述 | 本章将详细介绍、下面将从以下几个方面、如下所示、具体如下、本文将、本手册旨在全面阐述 |
| 制作过程 | 已按规范生成、已修复旧版、配图策略、验收门禁、纯文字首页要求、避免后文无图 |
| AI/助手腔 | 作为 AI、我帮你、为您生成、智能撰写、自动整理如下 |
| 万能宣传 | 一站式解决方案、全方位赋能、助力数字化转型、打造闭环生态、赋能业务升级 |
| 空洞程度词堆砌 | 高度智能、深度融合、全面覆盖、极致体验、卓越性能（无数据/无对象时） |
| 空壳句 | 进入相应模块、填写信息、保存即可、点击相应按钮、进行相应操作、按需配置 |

## 三、手册慎用词（每本手册合计 ≤3 次，且必须绑定具体对象）

- 首先 / 其次 / 最后（改为按真实操作序号或时间顺序写）
- 高效、便捷、快速、一键（必须写清点了哪个按钮、耗时或结果字段）
- 用户可、系统将、支持对…进行…（改为祈使句 + 真实控件名）
- 闭环、链路、抓手、对齐、拉通、沉淀、赋能（必须写成具体状态流转，如「复核通过后写入归档版本 V1.2」）

## 四、手册「人味」写法（正面规则）

1. **界面锚点**：写真实控件与状态词，如「左侧菜单『系统管理』→『用户管理』」「按钮『提交复核』」「状态『待复核→已归档』」。
2. **操作步骤格式**：每步尽量「定位控件 → 动作 → 可见反馈/状态字」；反馈写真实提示文案，如「页面顶部出现绿色提示条『保存成功』」。
3. **异常处理**：写真实失败提示与处置，如「提示『该编号已存在』时，返回列表页修改编号后重新提交」。
4. **版本与缺陷口吻**：写「当前版本 V1.0.3 在…情况下会…，临时处理是…，已在 PR-#12 修复待发」。
5. **角色动作差**：操作步骤用「操作员/复核员/管理员」等业务角色，避免全文「我们团队」；需求组只出现在需求/验收叙述。
6. **句长节奏**：短指令句与稍长的异常说明交替；不要每步都 40–70 字刻成同一模子。
7. **段落起笔多样化**：有些段直接从按钮、状态或异常提示起笔，不要每段都是「概述—步骤—总结」小论文结构。

## 五、中文手册特有 AI 痕迹（追加检查项）

在通用模式目录之外，手册正文重点复查：

- **排比三连**：连续三个「通过…实现…」「不仅…而且…还…」等整齐结构。
- **纠正式模板**：「不是 X，而是 Y」「关键在于」「真正…的是…」密集出现。
- **推论台阶**：「这意味着→这说明→进一步→由此可见」连接词链。
- **对称骨架**：每段同长度、同首句、同一收束。
- **收尾升华**：每段以「这说明/体现了/彰显了」封口。
- **开头复述任务**：「基于您的需求」「下面将介绍」「本章将」。
- **虚化动词堆叠**：实现、支持、提升、确保、促进连续出现且无对象和结果。
- **同构步骤**：所有步骤都是「点击X→输入Y→点击Z」且无任何状态/异常差异。

## 六、手册专用检查清单（写入 Word 前执行）

1. **换行业测试**：把软件全称、对象名、场所名替换为另一无关行业后，若整段步骤/异常/专属动作仍通顺 → 模板化，重写该段。
2. **同级案例换词**：与最近 1–3 个案例并排看章节、步骤、图注和异常；连续 3 句以上仅名词不同即返工。
3. **公开通用句**：删除「B/S 架构、信息录入查询统计、界面友好操作简便」等公开说明书常见空壳句。
4. **禁用词扫描**：第二节禁用词清零；第三节限制词未滥爆。
5. **界面锚点检查**：每个关键步骤有真实菜单/按钮/字段/状态/提示语。
6. **事实冻结**：软件全称、版本号、菜单、按钮、字段、状态、接口、错误提示、日期、PR/提交号、数据口径不得改动；缺证据时保留缺口，不用想象内容填空。
7. **节奏检查**：句长、段长、句首有自然变化；相邻段落有明确差异。
