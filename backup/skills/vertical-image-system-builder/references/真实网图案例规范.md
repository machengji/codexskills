# 中国境内真实网图案例素材规范

本规范是 `vertical-image-system-builder` 的强制素材门禁。默认业务系统面向中国用户和中国现场，**真实案例图必须描绘中国境内场景**；除非用户明确指定某个外国国家/地区，否则不得下载、保留、引用或交付外国场景图片。

## 1. 默认地域规则

```text
默认：只使用中国境内真实图片（优先中国大陆）
例外：用户明确要求某个外国国家/地区时，才允许该指定地域
禁止：因中国图片难找、下载失败或槽位不足，用外国图片补位
```

- “来源网站在国外”不等于“外国图片”。可使用 Wikimedia Commons 等网站，但画面实际地点必须明确位于中国境内。
- “亚洲图片”不能替代“中国图片”。日本、韩国、泰国、新加坡、印度等亚洲国家图片仍属于外国图片，默认禁止。
- 用户提供图片时也要核对地点；无法确认中国地点的图片不得计入最低数量。
- 软件名称明确指向外国业务且用户明确确认时，可使用指定外国场景，并在 `设计说明.md` 记录例外原因；不得顺带混入其他国家图片。

## 2. 最低数量与覆盖

每个项目至少满足：

1. 中国境内真实案例图 ≥6 张，且为不同画面；
2. 至少覆盖 3 个业务页面；
3. 核心影像链路（载入→处理→标注→对照）至少有 2 张中国真实原始图；
4. 登录页如使用真实图，也必须是中国名称对象/场所，不得用外国城市或展厅营造氛围；
5. 中国真实图不足 6 张时，素材门禁不通过，继续搜索，不得用外国图片凑数。

## 3. 中国地点证明门槛

每张图片在下载前必须至少有一种可复查的中国地点依据：

- 文件页标题或说明明确写出中国、省、市、区县或中国地名；
- 文件页提供位于中国境内的坐标；
- 中国政府、院校、行业机构或企业公开页面明确说明拍摄地点；
- 用户提供并明确说明拍摄地点在中国。

不得仅凭建筑风格、人物面貌、车牌模糊轮廓或主观感觉判断“中国图片”。地点无法证明时不下载、不登记、不使用。

## 4. 名称与业务绑定

每张图还必须同时通过：

- **名称关联**：对应软件全称中的对象、场所、工具或结果；
- **业务用途**：承担案例、证据、对照、标注底图、复查前后之一，不是背景墙纸；
- **行业不可替换**：换成另一行业后明显违和；
- **可处理性**：支持校正、标注、局部放大、遮罩或前后对比至少一种；
- **地域一致性**：画面和页面文案均服务中国现场，不出现外国地点暗示。

## 5. 来源优先级与授权

按以下顺序选用：

1. 用户提供且地点明确为中国的真实图片；
2. 项目内已有、地点可证且授权清晰的中国图片；
3. 中国政府、院校、行业公开资料中的现场图；
4. Wikimedia Commons、图库等许可清晰且文件页明确证明中国地点的图片；
5. 其他可追溯来源：仅限地点明确为中国、可写清来源页与演示用途的图片。

禁止使用无法说明许可、来源页或中国地点依据的图片。

## 6. 台账字段（强制）

项目必须创建 `public/cases/manifest.json`，并在 `设计说明.md` 同步台账。每条至少包含：

| 字段 | 要求 |
|---|---|
| `file` 或本地路径 | 如 `china-shenzhen-showroom-01.jpg` |
| `country` | 固定写 `中国` |
| `location` | 中国省/自治区/直辖市 + 城市 + 可选区县/场所 |
| `locationEvidence` | 证明中国地点的文件页、坐标或来源说明 |
| `sourcePage` | 可回访的原始页面 |
| `license` | 许可/授权说明 |
| `author` | 作者或来源机构（可获取时） |
| 名称词根 | 对象/场所/工具/结果 |
| 使用页面 | 路由或页面名 |
| `role` | 原始案例/处理前/处理后/证据/对照等 |
| 下载时间 | ISO 日期 |

文件名建议以 `china-省市-业务对象-序号` 开头，便于静态检查。品牌或个人敏感信息需要处理时，保留原始合规副本，将去标识版本用于运行，并在台账记录处理方式。

## 7. 本地化与目录清洁

1. 运行图片统一放到 `public/cases/`；
2. 原始合规副本如需保留，放到 `public/cases/originals/`；
3. 代码只引用本地路径，外部 URL 只进入台账；
4. 外国图片下载失败记录、临时文件、旧版运行图不得残留在项目图片目录；
5. 替换素材后，必须同时清理源码引用、构建产物并重新截图；
6. `public/cases/`、原始素材目录和运行引用均要执行“外国场景数量为0”检查。

## 8. 自动校验（强制）

在项目根目录运行：

```powershell
python E:\machengji\.dsh\skills\vertical-image-system-builder\scripts\check_china_case_ledger.py .
```

校验必须通过：

- 台账 ≥6 条；
- 每条有中国地点、地点依据、来源、许可和业务角色；
- 台账文件存在；
- 运行引用全部在台账内；
- 目录不存在带明显外国地点关键词的图片。

仅当用户明确要求外国场景且 `设计说明.md` 已记录例外时，才可运行 `--allow-foreign`；不得为了绕过失败擅自使用该参数。

## 9. 下载失败与数量不足

1. 记录失败 URL 与错误；
2. 更换同一中国城市或同类中国现场的许可图片；
3. 扩展搜索到其他中国省市，但保持业务对象一致；
4. 仍不足时，本轮素材门禁不通过；
5. 可用 Canvas/矢量/程序化纹理补辅助槽位，但不得替代 ≥6 张中国真实案例图。

## 10. 影像处理与三维关系

- 中国真实图是案例底图与证据，不替代三维门禁；
- 三维仍以程序化组合建模为主；
- 影像处理必须让中国真实案例图产生可见前后变化；
- 不得用外国图片作为三维纹理、登录背景或隐藏补位素材；
- 图表仍按业务判断需要创建，不因素材丰富而堆装饰图表。

## 11. 验收勾选

- [ ] 中国境内真实案例图 ≥6 且全部本地化
- [ ] 至少覆盖 3 页，核心链路 ≥2 张中国原始图可处理
- [ ] 每张图有 `country: 中国`、具体地点与地点依据
- [ ] 每张图有来源、许可、名称词根、页面和业务角色
- [ ] 运行引用、案例目录和原始素材目录中的外国场景图片为 0
- [ ] 中国图片不足时未用外国图片补位
- [ ] 无生图、无无关装饰图、无热链主依赖
- [ ] 自动校验脚本结论为通过
- [ ] 替换素材后已重新构建并重做受影响截图/缩略拼图

任一项未通过：记录到 `验收记录.md`，继续修复，不得交付。

## 12. 明确禁止

- 禁止把“亚洲图片”当作“中国图片”；
- 禁止使用日本、韩国、泰国、新加坡、印度等外国图片冒充中国场景；
- 禁止因中国图片不足而用外国图凑满 6 张；
- 禁止只改页面图片、不清理源码、原始素材目录和构建产物中的外国图片；
- 禁止无中国地点依据、无来源、无许可或未本地化的图片；
- 禁止调用生图冒充中国真实现场；
- 禁止操作手册使用外国图片或无关网图充数。
