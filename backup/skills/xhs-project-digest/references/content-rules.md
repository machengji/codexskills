# 内容规则（融合版）

## A. 筛选硬规则（digest）
- 必须原创总结，用自己的判断重写
- 只保留项目类型与可行性结论
- 不粘贴来源站点正文
- 禁止网盘、提取码、课程原文、暴富承诺、绝对化成功学

### 每条笔记结构
1. 今天看了多少
2. 可做 1-2 个
3. 观察 0-2 个
4. 避雷 2-3 个
5. 筛选标准
6. 今日结论
7. 评论引导

### 推荐项最小字段
- 判断
- 适合谁
- 小验证（3-7 天可执行）

## B. 表达与生图规则（post-writer × gemini-3.1-flash-image）
- 封面生图模型：统一指定使用 `gemini-3.1-flash-image`
- 封面图规格：3:4 竖屏，小红书极简/高对比创业日记卡片风格

- 标题：人群/场景 + 具体张力 + 可核实结果
- 开头：最具体事实或反差，不写空泛时代开头
- 正文：指南/合集结构，先给标准再给项目
- 互动：窄问题，不直接要赞藏关
- 去 AI 味：少对称金句，少每段总结，保留真实不确定

## C. 标题偏好
- 今天看了N个项目，能做的只有X个
- 这周最不建议碰的3类项目
- 别先问赚不赚钱，先问有没有客户
- 想做副业先过这4道筛选

## D. 发布前必杀检查
- [ ] 无收益承诺
- [ ] 无网盘/提取码
- [ ] 无原文搬运
- [ ] 无人设崩塌（不装已经月入多少）
- [ ] 无“必火/稳过/百分百”
- [ ] 有至少 1 个可执行小验证
